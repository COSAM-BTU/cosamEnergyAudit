# cosamEnergyAudit

A runtime **discrete kinetic-energy audit** for the collocated finite-volume solvers of OpenFOAM. The library provides the function
object `kineticEnergyAudit`, which closes the discrete kinetic-energy budget of the **unmodified** `pimpleFoam` executable at every
time step, to round-off, and attributes the numerical energy error to the individual operators of the algorithm.

The momentum equation that the solver assembles is multiplied by the end-of-step velocity and decomposed exactly into the resolved
viscous dissipation and seven signed error contributions:

```
dK/dt = -eps_nu - e_time - e_conv - e_mesh - e_cont - e_pres - e_dev + e_iter
```

| Term | Meaning |
|---|---|
| `epsNu`  | resolved viscous dissipation of the implicit Laplacian (face based) |
| `eTime`  | time scheme (Euler / backward / Crank–Nicolson), split into storage and dissipative parts |
| `eConv`  | convection scheme, i.e. the deviation of the selected scheme from `linear` |
| `eMesh`  | mesh non-uniformity of `linear` interpolation (zero on a uniform hexahedral mesh) |
| `eCont`  | continuity error of the face flux |
| `ePres`  | pressure–velocity coupling (Rhie–Chow, including the transient flux correction `ddtCorr`) |
| `eDev`   | explicit transposed-gradient term of `linearViscousStress` |
| `eIter`  | algebraic residual (PISO splitting, linear-solver tolerance, nonlinearity lag) |

## Features

- Closes the discrete budget to round-off (`R_closure <= 2e-13` on hexahedral meshes, serial and in parallel)
- Runs with the **unmodified** solver executable; no recompilation of `pimpleFoam` is needed
- Rebuilds the operators with the case's own `fvSchemes`, so the measured terms are those of the user's setup
- Works in parallel on periodic hexahedral, perturbed-hexahedral and arbitrary polyhedral meshes
- Writes a global time series of every term and the signed **per-cell fields** (`eNum`, `nuNum`, `e_i`)
- Alternative attribution conventions (half-step multiplier, owner-side distribution, `phi^{n+1}` flux) in the same run
- Diagnostics: cumulative closure, masked numerical-viscosity indicator, `e_diff = epsNu - 2 nu (S:S) V`
- Offline mode: the same row can be recomputed from written fields with `pimpleFoam -postProcess`
- Measured overhead 4.5 to 6.5 % of the solver time

## Requirements

- OpenFOAM v2406 (ESI) or compatible, built in double precision
- Python 3 with NumPy for the post-processing tools

## Installation

```bash
git clone https://github.com/COSAM-BTU/cosamEnergyAudit.git
cd cosamEnergyAudit/src/cosamEnergyAudit
wmake libso
```

The library is placed in `$FOAM_USER_LIBBIN/libcosamEnergyAuditFunctionObjects`.

## Usage

Add the function object to `system/controlDict` of a case:

```
functions
{
    kineticEnergyAudit
    {
        type            kineticEnergyAudit;
        libs            (cosamEnergyAuditFunctionObjects);
        writeFields     true;        // per-cell fields at the write times
        writeControl    writeTime;
    }
}
```

and run the case as usual. The time series is written to
`postProcessing/kineticEnergyAudit/<time>/kineticEnergyAudit.dat`; the columns are listed in `doc/functionObject.md`.

### Requirements on the case

Laminar (or DNS-like) incompressible case, periodic or processor boundaries only, `Euler`, `backward` or `CrankNicolson` time
scheme, `Gauss linear` gradient, `Gauss linear corrected` Laplacian, unit relaxation and a fixed pressure reference.

## Tutorials

| Case | Description |
|---|---|
| `tutorials/tgv2D` | Two-dimensional Taylor–Green vortex at Re = 100, analytic solution, 32² mesh, serial |
| `tutorials/tgv3D` | Three-dimensional Taylor–Green vortex at Re = 1600, 16³ mesh, runs in seconds |

```bash
cd tutorials/tgv2D
./Allrun
```

Each tutorial prints the last rows of the audit, including the closure residual, which should stay at the level of 1e-14.

## Repository layout

```
src/cosamEnergyAudit/   function object source and Make files
tutorials/              two small verification cases
tools/                  case generator, mesh perturbation, post-processing, figure and table scripts,
                        pseudo-spectral reference solver, checkerboard indicators
solverPatch/            script that instruments a copy of pimpleFoam to write its own momentum residual
doc/DERIVATION.md       derivation of the discrete identity, term by term
doc/functionObject.md   column list, conventions and implementation notes
```

## Reproducing the paper

The campaign of the paper (78 runs) is generated by `tools/matrix.py` and `tools/makeCase.py`, post-processed by
`tools/paperData.py`, and turned into the figures and tables by `tools/paperFigures.py` and `tools/paperTables.py`. The extracted
data of every run are deposited separately (see the Citation section).
